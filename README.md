# Smartech Training Institute

This is a static frontend website for Smartech Training Institute.

## Files
- `index.html` — main landing page
- `style.css` — site styling
- `script.js` — frontend interactions and course listing
- `smartech logo.png` — site logo image

## Usage
Open `index.html` directly in a browser or serve the folder with a simple static server.

Example:
```bash
cd /home/dipanshu/Downloads/institue
python3 -m http.server 8000
```
Then open http://localhost:8000.
